# Landholder Dominance and Moisture Flows

## Overview

This research project investigates how landholder groups and land use in the Amazon influence atmospheric moisture recycling, regional rainfall, and ecosystem resilience. Its analytical workflows were designed to combine land-cover, property, and climate data to map landholder dominance, estimate moisture connections, assess resilience scenarios, and characterize moisture footprints.

## Research workflow

The project’s analyses cover the following themes:

1. **Landholder dominance:** Prepare spatial landholder-dominance analyses using MapBiomas and HILDA+ land-cover products.
2. **Property data:** Analyze SICAR property data and compare landholder classifications.
3. **Moisture recycling:** Estimate moisture recycling using MapBiomas- and HILDA+-based land-use inputs.
4. **Resilience:** Assess rainfall and ecosystem-resilience scenarios over the Amazon study area.
5. **Moisture footprints:** Summarize and visualize moisture footprints, including volumetric results.

These are descriptions of the project’s prior analysis areas, not runnable instructions: the current `main` branch contains this README only; the analysis notebooks and other project files are not currently included.
